How To Use

Using the wheel is simple:

  1. Add some entries in the table
  2. Tweak the settings with the gear icon
  3. Save the wheel with the floppy disk
  4. Spin the wheel by clicking on it or [Spin]!

Fun Features

Putting a wheel name in curly brackets inside an entry like {New Wheel} causes a subspin if that entry is landed on! (note: make sure the wheel is saved!!)
Try making a wheel with the entries "0, 1, {Subwheel Test}{Subwheel Test}" and save it as "Subwheel Test"!

If you put an exclamation point before the wheel name (i.e. {!New Wheel}), it becomes exclusive.
An exclusive wheel cannot land on anything another exclusive wheel has already landed on.

Shortcuts

  • Ctrl + S: Save the wheel
  • Ctrl + Shift + S: Save the wheel as a new wheel
  • Ctrl + M: Make a new wheel
  • Ctrl + SPACE: Spin the wheel
  • Escape: Close most modals and stop the wheel
